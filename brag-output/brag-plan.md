# Brag Plan: AttendX (Polished Launch Edition with AI Narration)

## What is this app?
AttendX is an AI-powered optical attendance system that automates full-class roll call in 1.8 seconds using OpenCV YuNet face detection, canonical 5-point alignment, and SFace 128-d deep facial recognition with a teacher-in-the-loop active learning loop.

## The angle
"One Photo. Verified in 1.8 seconds." A high-end, premium product film showing the authentic AttendX web platform in action: no generic cartoon graphics, but the real Swiss-designed web interface, live computer vision HUD, teacher verification ledger, and active learning biometric updates.

## Tone & Options
- Preset: `polished`
- Creative direction: Restrained, elegant Swiss minimalist product film with dark slate aesthetics and natural voiceover narration.
- Voice narration: Enabled (`/brag --voice`)
- Visual identity: Exact AttendX SVG brand mark (`#2563EB` accent), Swiss hairline grid (`#27272a`), Inter and JetBrains Mono typography.
